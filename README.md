# 나만의 퀴즈 게임

## 프로젝트 개요
터미널에서 실행되는 콘솔 기반 퀴즈 게임입니다. Python 기본 문법과 클래스(객체 지향),
JSON 파일 저장을 이용해 퀴즈를 출제/등록하고 점수를 관리할 수 있습니다.
코디세이(Codyssey) 미션 2로 진행한 프로젝트입니다.

## 퀴즈 주제 선정 이유
주제: 영화
(여기에 왜 이 주제를 골랐는지 한두 문장 추가하세요. 예: 평소 영화를 좋아해서
가장 익숙하고 재미있게 문제를 만들 수 있는 주제였습니다.)

## 실행 방법
```bash
python3 main.py
```
Python 3.9 이상이 설치되어 있어야 하며, 외부 라이브러리 설치 없이 표준 라이브러리만으로 동작합니다.

## 기능 목록
- 퀴즈 풀기: 저장된 퀴즈를 순서대로 출제하고, 정답/오답을 판정하여 결과와 점수를 보여줍니다.
- 퀴즈 추가: 새로운 문제(문제/선택지 4개/정답 번호)를 입력받아 등록합니다.
- 퀴즈 목록: 등록된 모든 퀴즈의 문제를 목록으로 확인합니다.
- 점수 확인: 지금까지의 최고 점수를 확인합니다.
- 잘못된 입력(공백, 문자, 범위 밖 숫자, 빈 입력) 처리 및 Ctrl+C / EOF 시 안전 종료

## 데이터 파일 설명 (state.json)
프로젝트 루트의 `state.json`에 UTF-8 인코딩으로 저장됩니다.
프로그램 실행 시 `QuizGame` 클래스가 자동으로 이 파일을 읽어오며,
파일이 없거나 손상된 경우 기본 퀴즈 데이터로 시작합니다.

스키마 예시:
\```json
{
  "quizzes": [
    {
      "question": "문제 내용",
      "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
      "answer": 1
    }
  ],
  "best_score": 80
}
```
- `quizzes`: 등록된 퀴즈 목록 (문제/선택지 4개/정답 번호)
- `best_score`: 지금까지의 최고 점수 (아직 한 번도 풀지 않았으면 null)
